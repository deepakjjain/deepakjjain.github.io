DevCollab

Real-time collaborative workspace for engineering teams — shared Markdown docs, live cursors, and threaded code review backed by Operational Transformation.

Next.jsTypeScriptWebSocketsMongoDBExpressDockerTailwind CSS
View Source

Challenge

A 30-person remote team was spreading technical discussion across Slack, Notion, and GitHub comments. Design rationale was scattered. Context was lost between tools. Nothing was linked to the code it described.

The goal: one place for async and live technical discussion, scoped to projects and linked to code.

Architecture

WebSocket rooms per document. Each document gets its own Socket.io room. Clients join on open, leave on close. The server broadcasts delta operations only to room members — bandwidth stays minimal.

Operational Transformation for conflict resolution. Last-write-wins loses edits. OT merges concurrent changes without losing either author’s intent. Built on ot-json0 with a custom revision protocol — clients tag each operation with the server revision it was based on, and the server transforms it against everything that arrived since.

MongoDB for document storage. Block-based structures (paragraphs, code blocks, headings) map naturally to nested JSON. Versioned snapshots stored every 50 operations for rollback support.

Optimistic UI updates. Changes apply immediately in the client, then confirm or roll back based on server acknowledgement. Keeps the editor feeling instant even on high-latency connections.

Next.js App Router. Server components for the document sidebar (cached, rarely changes), client components for the live editor. Reduced initial JS bundle by ~35%.

What I Built

  • Real-time Markdown editor with live cursors and user presence indicators
  • Block-based document structure supporting code blocks, tables, callouts, and embeds
  • Threaded comments anchored to specific document ranges
  • Project workspace with member roles (owner, editor, viewer) and invite links
  • Full-text search across all workspace documents via MongoDB Atlas Search

Results

  • Edit latency: sub-100ms round-trip for same-continent users
  • Data integrity: zero data loss incidents across 3 months of beta with 200+ active users
  • Adoption: replaced Notion for internal technical docs at the target team within 6 weeks
  • Bundle size: 142 kB first-load JS (gzip)
