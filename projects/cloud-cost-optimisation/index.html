Engineering Manager

AWS Cloud Cost Optimisation

$500K+ AWS spend reduction through FinOps practices — tagging enforcement, Reserved Instances, right-sizing, and a cost visibility layer built before any cuts were made.

AWSTerraformCost ExplorerCloudWatchGrafanaPythonAWS BudgetsSavings Plans

Challenge

Multiple AWS accounts running across engineering teams with no central cost visibility. Spend was growing month-over-month. No clear picture of which teams, services, or environments were responsible.

You can’t optimise what you can’t see. Before touching a single instance, the problem was visibility.

Approach

Cost visibility layer first. Built a cost reporting pipeline using AWS Cost and Usage Reports (CUR) delivered to S3, queried with Athena, and visualised in Grafana. For the first time, teams could see their own spend — broken down by service, environment, and resource. Monthly cost reviews started from this dashboard.

Tagging enforcement via CI. Defined a mandatory tagging taxonomy: team, environment, service, cost-centre. Updated all Terraform modules to require these tags at resource creation. Added a CI check that fails any plan creating untagged resources. Compliance went from ~30% to 95% across all accounts.

Reserved Instances and Savings Plans. Pulled 12 months of usage data to identify stable, predictable workloads. Purchased 1-year Reserved Instances for baseline EC2 and RDS capacity. Applied Compute Savings Plans for Lambda and Fargate workloads. Combined coverage brought on-demand exposure down to volatile and new workloads only.

Right-sizing. CloudWatch metrics analysis identified EC2 and RDS instances running at consistently low CPU and memory utilisation. Worked with service owners team-by-team — presented the data, agreed on the target instance type, coordinated the resize. No guessing, no performance incidents.

Dev and staging hygiene. Scheduled stop/start for non-production EC2 and RDS instances outside working hours using EventBridge and Lambda. Auto-termination for instances tagged ephemeral after 24 hours. These two changes alone cut dev account costs significantly.

What I Built

  • CUR pipeline: S3 → Athena → Grafana cost dashboards with team-level showback
  • Terraform tagging module enforced across all new resource creation
  • CI compliance check — rejects plans creating resources without required tags
  • Right-sizing analysis script using CloudWatch GetMetricStatistics — outputs per-instance CPU/memory p95 over 30 days with recommended instance family
  • EventBridge + Lambda automation for dev environment scheduled shutdown
  • Monthly cost review process and runbook adopted across engineering leadership

Results

  • $500K+ total AWS spend reduced
  • Tagged resource compliance: ~30% → 95% across all accounts
  • Reserved Instance and Savings Plan coverage: 70%+ of baseline compute
  • Dev and staging accounts: significant reduction from scheduled shutdowns alone
  • First month-over-month cost breakdown by team and service — enabled a targeted optimisation backlog
  • Zero performance incidents from right-sizing changes
