Lead Full-Stack Developer

Analytics Dashboard

Internal BI platform cutting 90-second queries to under 400ms on a 50M-row database — materialized views, async exports, and per-user Redis caching.

PythonFastAPIPostgreSQLRedisCeleryReactTypeScriptDocker
View Source

Challenge

Queries against a 50M-row events table were taking 45–90 seconds. Sales and ops teams had stopped trusting the dashboards. By the time a report loaded, someone had already pulled the numbers from a spreadsheet.

The constraint: make reports feel instant without rewriting the data model.

Architecture

Materialized views for common aggregations. Pre-computed daily, weekly, and monthly rollups in PostgreSQL. Refreshed every hour via Celery Beat using REFRESH MATERIALIZED VIEW CONCURRENTLY — reads continue against old data during refresh, no locked window. Cut common queries from 60s to under 200ms.

Redis caching with per-user keys. Query results cached for 10 minutes. Cache key includes user ID and a hash of the query parameters. Prevents cross-user data leakage while serving repeated loads fast.

Celery for heavy exports. CSV and PDF exports run as background tasks. Users get an immediate “processing” state and poll for completion. Eliminates request timeouts on large datasets entirely.

FastAPI + asyncpg. Non-blocking PostgreSQL driver for async request handling. Pydantic schemas enforce strict input validation. OpenAPI docs generated automatically.

React Query on the client. Stale-while-revalidate keeps dashboards feeling live without hammering the API on every render.

What I Built

  • FastAPI REST API with JWT auth, role-based access control, and rate limiting
  • Celery task queue for scheduled report generation, email delivery (SendGrid), and CSV/PDF exports
  • React dashboard with filterable charts, date-range pickers, and saved views
  • Admin panel for user permissions, job queue status, and manual view refreshes
  • Test suite: pytest (92% coverage), Playwright for E2E dashboard flows

Results

  • Query latency: 45–90s → 150–400ms (−99%) for all pre-defined report types
  • API uptime: 99.94% over 12 months
  • Export throughput: 10,000-row CSV export in under 8 seconds (down from 3-minute timeout)
  • Test coverage: 92% — caught 3 regressions before production
